# Your Life Time

Your whole life, on one page.

https://randalhsu.github.io/YourLifeTime/
* Each dot is one week. Each row is one year. That's it. That's all of it.
* The filled dots are gone forever; the hollow ones are all you have left.
* Somewhere in between, one dot glows quietly: **this week. Right now. The one you're spending as you read this.**

## Usage

Open `index.html` in a browser. Fill in your birthday and life expectancy in the form, or pass them via URL:

```
index.html?birthday=2000-01-01&expectancy=80&theme=ocean
```

Bookmark your URL, set it as your new-tab page, and let it greet you every morning.

## URL parameters

| Param | Values | Default |
|---|---|---|
| `birthday` | `YYYY-MM-DD` | `2000-01-01` |
| `expectancy` | integer 1 to 100 | `80` |
| `theme` | `auto`, `dark`, `light`, `paper`, `sepia`, `ocean`, `sky`, `forest`, `mint`, `midnight`, `sakura` | `paper` (`auto` follows system) |
| `shape` | `dot`, `square` | `dot` |
| `lang` | `en`, `zh` | browser language |
